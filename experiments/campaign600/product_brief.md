# Flow — готовый сервис тематических видеорекомендаций

Пользователь хочет готовый минималистичный веб-сервис: вертикальная лента как в
TikTok, фильтрация по темам, рекомендации и обратная связь. Видео — ПО ВНЕШНИМ
ССЫЛКАМ. Весь продукт должен запускаться на обычном VPS после задания домена.
Собери реальный продукт, не прототип с кнопками-заглушками. Интерфейс на русском.

Стек: Python 3.12+, FastAPI, SQLite (WAL), статический HTML/CSS/JS без сборщика;
один процесс Uvicorn. Доступны fastapi 0.136.3, uvicorn 0.49.0, httpx 0.28.1,
pytest 9.0.3. Используй stdlib для паролей/сессий, либо явно укажи зависимости.
Нет внешних API-ключей. Docker Compose + Caddy для автоматического HTTPS.

## Поведение

1. Красивый адаптивный интерфейс: тёмный фон, крупная карточка видео по центру,
   тонкая навигация, чипы тем, читаемая типографика; мобильный свайп/scroll-snap и
   клавиши вверх/вниз. На десктопе удобная боковая панель. Никакого горизонтального
   скролла. Состояния загрузки, ошибки сети, пустой каталог и конец ленты.
2. Просмотр доступен гостю. Сессия гостя и её предпочтения сохраняются. Регистрация
   (username/password), вход, выход; перенос гостевых реакций при входе, личное
   избранное. Для cookie — HttpOnly, SameSite; Secure в production; CSRF-защита
   мутаций. Пароли хешировать с солью и дорогим KDF. Ограничение попыток входа.
3. Каталог внешних URL: HTTPS YouTube (watch/shorts/youtu.be → безопасный iframe),
   Vimeo, прямые HTTPS MP4/WebM (HTML video). Нельзя принимать javascript/data/file,
   localhost/private IP, произвольный HTML/embed-код. Сервер не скачивает и не
   проксирует URL. Если встраивание запрещено провайдером, доступна кнопка
   «Открыть источник». Ссылки с rel=noopener noreferrer, никакого innerHTML из БД.
4. Темы, строковый поиск по названию/описанию, сортировки «Для вас»/«Новое»/
   «Популярное», пагинация без повторов в текущей выборке. Видеоплеер только у
   активной карточки; соседние видео не должны одновременно играть. Звук управляется
   пользователем; autoplay muted и обработка отказа браузера.
5. Лайк toggle, «Не интересно»/скрытие, избранное toggle, просмотр и время просмотра,
   жалоба с причиной. Повторные события не накручивают счётчики; ограничить допустимое
   время и частоту событий. Объяснение «Почему это видео». Предпочтения по темам и
   сигналам просмотров/реакций влияют на ранжирование; скрытое больше не показывать.
   Сохранить небольшую долю исследования новых тем и детерминированный порядок
   внутри пагинации. Действия влияют на данные, не только на цвет кнопок.
6. Комментарии зарегистрированных пользователей, удаление своего комментария,
   админская модерация комментариев и жалоб. Ограничения длины/частоты.
7. Админка с авторизацией: добавить/редактировать/удалить или скрыть видео,
   указать URL, заголовок, описание, темы; посмотреть жалобы и обработать их.
   Обычный пользователь не имеет админских прав. Учётная запись администратора
   создаётся из переменных окружения, без встроенного стандартного пароля.
8. Небольшой явно помеченный демонстрационный каталог внешних видео для первого
   запуска. В production его можно выключить. Не утверждай, что видео просмотрено
   сервером; не выдумывай содержимое роликов. Метаданные вводятся администратором.
9. Страница/диалог приватности: локально хранимые предпочтения, внешние провайдеры
   видят сетевые обращения при воспроизведении. Сброс истории/предпочтений и удаление
   своего аккаунта. Не добавляй стороннюю аналитику или платные сервисы.

## Конкретный контракт для независимой проверки

- Точка ASGI: `app.main:app`. `GET /api/health` возвращает JSON со status=ok.
- `GET /api/session` устанавливает гостевую сессию, возвращает user (null либо
  объект с username/is_admin) и csrf_token. Для мутаций клиент посылает X-CSRF-Token.
- POST `/api/auth/register`, `/api/auth/login`: JSON username/password;
  POST `/api/auth/logout`.
- `GET /api/topics`; `GET /api/feed?topic=...&q=...&sort=for_you&limit=...&cursor=...`
  → JSON items (id/title/url/provider/topics/reason/liked/saved), next_cursor.
- `POST /api/videos/{id}/feedback`: JSON kind (like/save/hide/watch/report),
  value (bool, для toggle), watch_seconds (для watch), reason (для report),
  event_id (строка, дедупликация в пределах сессии). `GET /api/saved`.
- GET/POST `/api/videos/{id}/comments`; DELETE `/api/comments/{id}`.
- POST `/api/admin/videos`: JSON title/url/description/topics; PATCH/DELETE
  `/api/admin/videos/{id}`; GET `/api/admin/reports`, PATCH `/api/admin/reports/{id}`.
- POST `/api/privacy/reset`; DELETE `/api/account`.
- Все SQL параметризованы, транзакции откатываются при ошибках, FK включены.
  Неправильный ввод возвращает 4xx. Нельзя удалить/изменить чужие приватные данные.
- Переменные: DATABASE_PATH, APP_ENV (development/production), SECRET_KEY,
  ADMIN_USERNAME, ADMIN_PASSWORD, DOMAIN, SEED_DEMO (0/1). Не печатать пароли в логах.

## Доставка и проверки

Создай Dockerfile (не root), compose.yml (только Caddy публикует 80/443), Caddyfile,
requirements.txt с версиями, README.md на русском, config.example (не секретный
файл), скрипт `setup.py DOMAIN`, создающий случайные SECRET_KEY/ADMIN_PASSWORD и
локальный .env с правами 0600 только при явном запуске владельцем; не перезаписывать
существующие настройки. Предусмотри data volume, healthcheck, restart, backup и
restore SQLite с проверкой целостности, инструкции обновления/отката. Обычный VPS,
один сервер, без Kubernetes. Docker socket в контейнер не монтировать.

Напиши независимые от внешних видеохостингов тесты основных API и безопасности.
Зарегистрированная проверка `unit` уже запускает pytest. Прогони её и исправь
ошибки. Дай фактические команды развёртывания. Никаких TODO вместо функций.

Ты работаешь в отдельном одноразовом проекте. Разрешены генераторы файлов с
project_write=true и network=false только внутри него, если это ускорит создание
нескольких файлов. Нельзя менять harness, его окружение, прочие каталоги или
запускать Docker самостоятельно. Внешний оператор отдельно проверит контейнерную
сборку, браузер и развёртывание. Установка пакетов и веб-поиск здесь не требуются.
Используй короткие рабочие заметки, избегай повторных чтений неизменённых файлов.
