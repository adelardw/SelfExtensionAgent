# Skill: app_control (core)

СТРУКТУРНОЕ управление приложениями через их родные API (AppleScript) — **без
костылей-скриншотов**. macOS. Читает и меняет состояние приложений напрямую.

## Когда использовать
- Прочитать открытые вкладки Safari, открыть сайт в браузере.
- Составить/отправить письмо (Mail), создать заметку (Notes).
- Узнать, какие приложения запущены.

## Инструменты
- `list_running_apps()` — список запущенных приложений.
- `safari_tabs()` — заголовки и URL всех вкладок Safari.
- `safari_open(url)` — открыть URL в Safari.
- `compose_email(to, subject, body, send=False)` — письмо в Mail (отправка только при send=True).
- `create_note(title, body)` — заметка в Notes.

## Важно
- Нужны разрешения macOS **Automation** (System Settings → Privacy → Automation).
- `AGENT_DRY_RUN=1` — не выполнять реальные действия (для тестов).
- Отправка писем и прочее необратимое — только с подтверждением пользователя.
- Нескриптуемые приложения — следующий шаг (Accessibility AX-дерево через pyobjc).
