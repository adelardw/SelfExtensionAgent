Этот навык позволяет рекурсивно исследовать структуру проекта и читать файлы из любых поддиректорий. 
Используйте его для:
1. Получения полного дерева проекта (все папки и файлы).
2. Поиска файлов по расширению или имени во всем проекте.
3. Чтения содержимого файлов в глубоких поддиректориях.

Примеры:
- `get_project_tree(".")` — показать структуру текущей папки.
- `read_project_file("src/utils/helper.py")` — прочитать файл по относительному пути.
