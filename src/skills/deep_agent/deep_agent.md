# Skill: deep_agent (core, дополнение)

Запускает LangChain **DeepAgent** для долгогоризонтных/файловых подзадач:
виртуальная ФС + todo-список + спавн суб-агентов — из коробки. Это **дополнение**
к ядру, а не замена: основной граф остаётся, deep_agent вызывается лишь на тяжёлых
многоступенчатых шагах.

## Когда использовать
- Задача требует промежуточных файлов/черновиков, плана на много шагов,
  делегирования суб-агентам (например: исследовать тему → написать несколько
  файлов → собрать итог).

## Когда НЕ использовать
- Простые шаги, разовые вопросы — это дорогой путь, ядро справится дешевле.

## Инструмент
- `run_deep_agent(task, max_steps=40)` → итог работы deep-агента (+ список файлов
  в его виртуальной ФС).
