У тебя есть инструмент `run_deep_agent` — мощный долгогоризонтный агент с виртуальной
ФС, todo-списком и суб-агентами.

Используй его ТОЛЬКО когда текущий подшаг по-настоящему тяжёлый и многоступенчатый
(нужны черновики/файлы, план на много действий, делегирование). Для обычных шагов
решай сам доступными инструментами — deep_agent дорогой.

Сформулируй для `run_deep_agent` самодостаточную задачу одним сообщением и используй
его результат как итог подшага.
