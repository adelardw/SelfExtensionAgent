# Skill: web_search (core)

Нормальный веб-поиск и чтение страниц через stealth-браузер **cloakbrowser**
(drop-in замена Playwright, проходит антибот-детект). Базовый защищённый навык.

## Когда использовать
- Нужна свежая информация из интернета (новости, факты, документация).
- Нужно прочитать конкретную страницу целиком (deep-read для RAG).

## Инструменты
- `search_web(query, max_results=8)` → ранжированный список (title, url, snippet)
  из DuckDuckGo через stealth-браузер. При сбое — HTTP-фолбэк.
- `read_url(url, max_chars=4000)` → читаемый текст страницы. Используется как
  второй шаг agentic-поиска: сначала `search_web`, затем `read_url` по лучшим ссылкам.

## Выход
Форматированный текст. Ссылки очищены от редиректов DuckDuckGo.

## Замечания
- Не требует API-ключей.
- Деградирует на urllib, если Chromium недоступен.
