# Skill: device_control (core)

Действия с устройством **по запросу из чата** (on-demand, не фоновый мониторинг).
macOS, штатные утилиты, без сторонних зависимостей.

## Когда использовать
- Пользователь просит открыть сайт/приложение, показать уведомление, озвучить ответ.
- Нужно «посмотреть» на экран — сделать скриншот для последующего анализа.

## Инструменты
- `open_url(url)` — открыть страницу в РЕАЛЬНОМ браузере пользователя. Веб-сервисы
  (почта, календарь, соцсети, кабинеты) открывай ИМЕННО так и с КОНКРЕТНЫМ адресом
  сервиса: «Яндекс Почта» → `mail.yandex.ru`, «Gmail» → `mail.google.com` (не главная
  страница и НЕ open_app — отдельного приложения у веб-сервисов обычно нет).
- `open_app(app_name)` — открыть УСТАНОВЛЕННОЕ приложение ('Mail', 'Safari', 'Calendar'…).
- `capture_screen()` — скриншот (путь к PNG) для multimodal/vision-шага.
- `notify(title, message)` — desktop-уведомление об активности.
- `speak(text)` — озвучить ответ системным голосом (TTS-фолбэк; облачный — OpenRouter TTS).

### Работа с УЖЕ открытыми приложениями (System Events)
- `scroll(direction, amount)` — скроллить открытый браузер/окно (down/up).
- `type_text(text)` — печатать в активное окно.
- `press_key(key)` — enter/tab/escape/pagedown/pageup/up/down/space.
- `send_telegram(text)` — написать и отправить сообщение в Telegram Desktop.

Требуется разрешение macOS **Accessibility** (System Settings → Privacy → Accessibility)
для процесса, запускающего агента. Чувствительные действия — с подтверждением пользователя.

## Важно
- Только базовые безопасные действия. Чувствительное (отправка писем, звонки) —
  через отдельный слой с подтверждением пользователя (human-gate).
