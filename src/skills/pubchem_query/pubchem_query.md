# PubChem Query Skill

Навык для запросов к базе данных PubChem через PUG REST API (публичный, без ключа).
Позволяет искать соединения, получать их свойства, классификации, ферментативные трансформации, генные ко-оккуренции и другую информацию.

## Когда использовать
- Когда нужна информация о химических соединениях из PubChem
- Для анализа молекулярных свойств (MW, heavy atoms, HBA, complexity и т.д.)
- Для поиска ферментативных трансформаций и генных взаимодействий
- Для работы с классификациями (например, Food Additive Status)

## Входы/Выходы
- Вход: запрос на русском или английском
- Выход: структурированные данные
