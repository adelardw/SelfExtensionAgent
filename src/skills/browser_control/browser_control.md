# Skill: browser_control (core)

Полноценные ДЕЙСТВИЯ в браузере ПОЛЬЗОВАТЕЛЯ через РАСШИРЕНИЕ (его профиль, его логины,
его вкладки — без перелогина, без чтения паролей/cookies): включить трек/видео, найти и
запустить музыку/фильм/плейлист, нажать, заполнить форму, сделать доставку, ходить по
страницам. Расширение не подключено → инструмент вернёт «НУЖНО РАСШИРЕНИЕ» с инструкцией:
передай её пользователю (ask_user), НЕ делай действие иначе (не подпроцессом, не поиском).

ФОНОВАЯ СРЕДА (по умолчанию): окно агента НЕ крадёт фокус — пользователь продолжает свою
работу (код/домашка/переписка), музыка играет фоном, он переключится на вкладку САМ когда
захочет. Запустил — дай короткий итог и остановись (не зацикливайся, не лезь на экран).
Браузер ЖИВЁТ между запросами: позже «поставь паузу», «продолжи», «расскажи вкратце что
играет», «порекомендуй» работают по той же открытой странице.

## Когда использовать
- «Включи трек/песню/альбом/видео/фильм», «поставь музыку», «запусти плейлист».
- Любое действие НА сайте: нажать, ввести в поиск, выбрать результат, плеер, форма.
- Когда нужно работать под логином пользователя в вебе.
(Для фонового сбора фактов — web_search; открыть ссылку в ОСНОВНОМ браузере юзера
без действий — device_control.open_url.)

Приём ОБЩИЙ для любого сайта/сервиса/источника, который назвал пользователь (или уместного
для задачи) — конкретные сайты ниже лишь ПРИМЕРЫ формы, не закрытый список.

## «Моё» на сервисе — навигация по МЕНЮ, не по угаданному URL (универсально)
Чтобы попасть в ЛИЧНЫЙ раздел («моё избранное / любимое / сохранённое / библиотека /
коллекция / плейлисты / корзина / заказы / история») — НЕ конструируй и не угадывай URL
(чужой логин в пути → пустая страница «ничего не нашлось», живой провал с
`users/yandex/playlists/liked-`). Вместо этого:
1. `browser_open` на ГЛАВНУЮ сервиса (или текущая страница), `browser_see`.
2. Найди в снапшоте пункт меню этого раздела по ТЕКСТУ (Коллекция / Библиотека / Моя
   музыка / Library / Saved / Liked / Корзина / Мои заказы…) и `browser_click` по нему.
3. `browser_see`/`browser_read` уже на нужной странице. Раздел и его адрес у каждого
   сервиса свои — приходи КЛИКОМ, это и есть универсальный приём (одинаков для ЯМ, Spotify,
   маркетплейса, доставки). Точные тексты пунктов — ТОЛЬКО из снапшота, не выдумывай.
ЧЕСТНОСТЬ: перечисляй ТОЛЬКО реально видимые в снапшоте элементы. Список виртуализирован
(подгружается прокруткой) — нет данных в снапшоте → `browser_scroll` и `browser_see` ещё
раз, либо честно скажи, сколько видно. НИКОГДА не дописывай/не выдумывай пункты, которых
нет на странице (вырожденный повтор = галлюцинация, запрещено).

## Выбор сервиса (пользователь сервис не назвал)
1. Память: каким сервисом он пользуется для этого ДОМЕНА задач (музыка/видео/еда/кино/
   покупки/…) — есть предпочтение → бери его без вопросов.
2. Нет предпочтения → выбери уместный популярный сервис САМ и действуй — не устраивай
   допрос из-за площадки. В итоговом ответе назови, через что сделал («заказал в X») —
   пользователь поправит, и это запомнится как предпочтение.
3. Видишь на странице ВЫБОР (альбомы, похожие треки, рестораны, блюда, фильмы) — обратимое
   решай сам (топ-результат) и предложи в итоге 2–3 альтернативы из снапшота; НЕОБРАТИМОЕ
   (платный заказ, бронь, отправка) — ask_user с вариантами.

## Паттерн работы (структурный, не скриншоты)
Каждый инструмент возвращает СНАПШОТ страницы: пронумерованные интерактивные элементы.
1. `browser_open(url)` — открой ГЛАВНУЮ нужного сервиса (его домен). НЕ угадывай URL поиска
   (`/search?q=`, `/index.php?search=` и пр. — у сервисов форматы РАЗНЫЕ, угадка часто 404).
   Затем `browser_see` → найди строку поиска → `browser_type(i, "<запрос>")` в неё. Если
   открытый URL дал 404/«не найдена» — вернись на ГЛАВНУЮ домена и ищи через её строку поиска.
2. Посмотреть снапшот → `browser_click(i)` по нужному элементу (строка трека, кнопка
   Play/Слушать, превью видео). Клик по треку обычно сразу запускает воспроизведение.
   Нужного элемента НЕТ в пронумерованном снапшоте (динамический дропдаун/оверлей SPA —
   результаты autocomplete и пр.)? → `browser_click_text("<видимый текст>")`: найдёт и кликнет
   элемент по тексту, минуя нумерацию снапшота.
3. Поле ввода → `browser_type(i, "текст")` (Enter автоматически).
4. Не видно нужного → `browser_scroll()` и `browser_see()`.
5. Пауза/продолжить видео — `browser_press("Space")`.

## Включить трек/видео (довести до звука, не «открыть»)
1. `browser_open` на страницу поиска сервиса.
2. `browser_see` → найди в снапшоте нужный результат, `browser_click` по нему.
3. Запусти ВОСПРОИЗВЕДЕНИЕ: на странице трека/видео нажми кнопку play/«Слушать»
   (`browser_see` → `browser_click` по ней) ИЛИ `browser_media("play")`.
4. ПОДТВЕРДИ: снапшот должен показать «♪ ЗВУК ИГРАЕТ» (или browser_media вернёт «играет ≥1»).
   Только тогда говори «играет». Не подтвердилось → честно скажи и попробуй кнопку плей
   (мог не залогиниться / это превью / кастомный плеер).

## Медиа и динамичный контент
«Поставь на паузу / продолжи / выключи звук» — `browser_media("pause"|"play"|"toggle"|
"mute"|"unmute")`: действует на ЛЮБОЕ медиа страницы (audio/video, в т.ч. внутренности
веб-плееров), без подтверждений. Снапшот показывает «♪ ЗВУК ИГРАЕТ», когда что-то играет.

## Заказ/доставка/корзина — ЧЕСТНАЯ РАМКА (не обещай автозаполнение)
Наполнить корзину и оформить заказ АВТОНОМНО агент НЕ берётся (сайты слишком разные —
надёжно не выходит, лучше честно, чем флейлить и жечь токены). Что делает агент:
- НАЙДИ варианты (сервисы/рестораны/товары/цены) — лучше через web_search (headless, дёшево) —
  и дай пользователю СПИСОК + ССЫЛКИ.
- При желании ОТКРОЙ нужную страницу/выдачу в его браузере (browser_open), чтобы он сам
  выбрал и оформил. Это и есть результат — не доводи до корзины/оплаты сам.
- НЕ обещай «добавил в корзину»/«оформил», если не подтверждено; не зацикливайся на кнопках «+».
Простые действия на сайте (включить музыку/видео, открыть/нажать одно) — делай как обычно.

## (опц.) Многошаговая форма/корзина — только если пользователь ЯВНО просит довести и помогает
Если пользователь настойчиво просит вести флоу: поиск → выбор → корзина → переход к оформлению.
ДВЕ ЖЁСТКИЕ ГРАНИЦЫ (агент их не пересекает САМ, в ЛЮБОМ режиме — это деньги/перс-данные):
1. ПОЛЯ персональных/платёжных данных (пароль, карта, документы): `browser_type` сам
   откажется печатать → попроси пользователя (ask_user) заполнить вручную и продолжай.
2. КНОПКА оформления/ОПЛАТЫ заказа («Оформить заказ», «Оплатить N ₽», «Заказать за N ₽»,
   «Подтвердить заказ»): `browser_click` сам ВЕРНЁТ «[ГРАНИЦА ОПЛАТЫ]» и НЕ нажмёт — потому
   что сохранённая карта = заказ в один тап без спроса = реальные деньги. Доведи корзину до
   готовности, покажи итог (что и на сколько) и попроси пользователя нажать финальную кнопку
   САМОМУ / подтвердить (ask_user). НЕ обходи это (ни по тексту, ни по селектору).
Обратимое (положить в корзину, выбрать опции, изменить количество) — делай сам.

### Доставка продуктов (Я.Еда/Лавка): МАГАЗИН vs РЕСТОРАН
Поиск товара (лимонад/чай/снеки/продукты) выдаёт ДВА типа результатов:
- МАГАЗИН/ЛАВКА (Пятёрочка, Магнит, Лавка, «ДадАли» и пр.) — у карточки есть кнопка «+»/«В
  корзину», добавляется ПРЯМО из выдачи. Для «положи в корзину <продукт>» ПРЕДПОЧИТАЙ их.
- РЕСТОРАН (кафе/пиццерии) — товар НЕ добавляется из общей выдачи: сначала ОТКРОЙ ресторан
  (клик по карточке) → его меню → там «Добавить». Если в выдаче только рестораны — открой
  один и добавь из меню, либо ищи в Лавке (продукты).
КНОПКА «+»/«В КОРЗИНУ» не сработала (DOM-клик не триггерит React) → `browser_tap(item)`
(trusted-клик, как настоящий тап) по той же кнопке из снапшота.

## Инструменты
- `browser_open(url)` — открыть страницу, вернуть снапшот элементов.
- `browser_see()` — текущий снапшот (что кликабельно, играет ли звук).
- `browser_click(item)` — клик по номеру элемента.
- `browser_type(item, text, submit=True)` — ввод в поле по номеру + Enter
  (в пароли/карты/документы НЕ печатает — граница доверия).
- `browser_media(action)` — пауза/плей/звук для любого медиа страницы.
- `browser_read()` — видимый ТЕКСТ страницы (для «расскажи вкратце» / «порекомендуй»).
- `browser_press(key)` — клавиша (Space, Enter, Escape…).
- `browser_scroll(direction)` — прокрутка.

## Важно
- Снапшот = правда о странице: выбирай элемент по его ТЕКСТУ в списке, не угадывай.
- Параметры (какой трек/видео/адрес) — ТОЛЬКО из текущего запроса пользователя.
- Действия идут под подтверждением пользователя (HITL), смотреть страницу и управлять
  воспроизведением по его просьбе — без вопросов.
