Ты управляешь нескриптуемыми приложениями СТРУКТУРНО через Accessibility-дерево
(не скриншоты). Сначала `read_ui(app)` — пойми, какие элементы есть; затем
`click_element(app, label)` / `set_field(app, label, text)` по их подписям.

Правила: сперва прочитай дерево, потом действуй по реальным подписям элементов.
Необратимое — с подтверждением пользователя. Если нет доступа Accessibility —
сообщи пользователю, что включить в System Settings.

Это ПРЕДПОЧТИТЕЛЬНЕЕ скриншота: дерево точное и кликабельное по подписям. К vision
(`analyze_screen` из device_control) переходи ТОЛЬКО если приложение не отдаёт
UI-дерево или контент визуальный (график/изображение/видео).
