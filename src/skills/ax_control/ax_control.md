# Skill: ax_control (core)

Структурное управление ЛЮБЫМИ приложениями через **Accessibility API (AX)** — ОС
отдаёт дерево UI-элементов (роль/заголовок/значение). Агент читает состояние и
действует ПО ЭЛЕМЕНТАМ (кнопки, поля), **не по пикселям/скриншотам**. Для
нескриптуемых приложений (там, где AppleScript не помогает).

## Инструменты
- `read_ui(app_name, max_depth=4)` — структурное дерево UI приложения.
- `click_element(app_name, label)` — нажать элемент по видимой подписи.
- `set_field(app_name, label, text)` — заполнить текстовое поле по подписи.

## Важно
- Нужно разрешение macOS **Accessibility** (System Settings → Privacy & Security →
  Accessibility → добавить Terminal/Python). Без него инструменты вернут подсказку.
- `AGENT_DRY_RUN=1` — действия (click/set) не выполняются; чтение безопасно.
- Связка: `app_control` (AppleScript) — для скриптуемых приложений, `ax_control` (AX) —
  для остальных. Оба структурные, без скриншотов.
