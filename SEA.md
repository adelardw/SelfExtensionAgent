# self-extension-agent

Самообучающийся агент на базе **LangGraph**, который рассматривает свой граф как обучаемую программу. Агент оптимизирует выполнение задач через «амортизацию»: успешные прогоны превращаются в навыки и паттерны, снижая стоимость и повышая качество последующих итераций.

## Архитектура
Система построена на графовой логике (LangGraph), где узлы отвечают за память, маршрутизацию, навыки, мышление и ревью.
- **Принцип работы:** Агент выбирает «режим мышления» под задачу, сохраняет контекст между сессиями и расширяет свои возможности через артефакты (навыки).
- **Потоки:** Входящие запросы (REPL, Telegram, Web, Chrome-расширение) попадают в граф, где маршрутизатор определяет путь обработки. Система поддерживает «амортизированный» цикл: выполнение → анализ следов → обновление навыков.
- **Интеграция:** FastAPI-бэкенд обеспечивает API для фронтенда и расширений, а также поддерживает нативное десктопное окно через `pywebview`.

## Ключевые модули
- `src/`: Основная логика агента. `agent.py` содержит топологию графа.
- `extension/`: Chrome-расширение для управления браузером пользователя (WebSocket-связь с локальным агентом).
- `frontend/`: React + Vite интерфейс (тонкий клиент, взаимодействующий с FastAPI).
- `scripts/`: Утилиты для бенчмаркинга (`amortize_bench.py`), генерации графа и оценки качества маршрутизации.
- `tests/`: Набор тестов, покрывающих логику навыков, работу с памятью, вычислительный слой и контуры самообучения.
- `data/`: Хранилище для SQLite-чекпоинтов и проектной памяти.

## Запуск и тесты
- **Запуск:** Используйте `sea` или `self-extension-agent` (CLI-команды).
- **Разработка:** Проект использует `uv`. Для установки зависимостей: `uv sync`.
- **Тестирование:** `pytest` (или `uv run pytest`).
- **GUI:** Для запуска десктоп-версии: `uv sync --group gui` и `python desktop.py`.

## Конвенции
- **Стиль:** Код должен быть модульным, с упором на типизацию (Pydantic).
- **Безопасность:** Не допускайте выполнения произвольного кода без явного подтверждения (HITL) в режиме `run_bash`.
- **Самообучение:** Любые изменения в логике графа должны сопровождаться обновлением `docs/architecture.en.drawio` и проверкой через `scripts/gen_agent_graph.py`.
- **Ограничения:** Не меняйте структуру `src/` без необходимости, так как она жестко завязана на конфигурацию `pyproject.toml`.
- **Инструкции для агента:**
    - При ответах придерживайся лаконичности и технической точности.
    - Всегда учитывай контекст из `MEMORY.md` и `SKILL.md` при планировании действий.
    - Если задача требует внешнего взаимодействия, используй инструменты из `src/browser_session.py` через расширение.
    - При внесении изменений в логику агента всегда проверяй, не нарушает ли это «амортизационный» цикл (сбор следов и их переиспользование).
