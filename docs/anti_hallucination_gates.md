# Анти-галлюцинация и роутинг: единая decision-таблица

Долг ревью: антивыдумочных/роутинг-гейтов много, они независимы и добавлялись под конкретные
провалы → их СОВОКУПНОЕ поведение нигде не описано, рефакторить страшно. Этот документ — единая
спека: что за гейт, где стоит, по какому порогу срабатывает, что делает, и куда «падает» при
неопределённости (fail-safe). Пороги живут в `config.yml` — здесь только карта и значения по
умолчанию. Поведение детерминированных гейтов закреплено в `tests/test_gates_characterization.py`
(меняешь порог/логику — падает характеризационный тест, т.е. решение становится осознанным).

Принцип fail-safe всей башни: **лучше лишний раз заземлиться/отказать честно, чем выдать выдумку.**
False-positive (зря заземлились) дёшев; false-negative (выдумка ушла юзеру) — дорог.

## Роутинг-гейты (куда вести прогон)

| Гейт | Где | Триггер / порог | Действие | Fail-direction |
|---|---|---|---|---|
| `_needs_web_grounding` | agent.py | intent-классификатор: label=`web_grounding`, порог `min_sim_per_label.web_grounding=0.23` | вести через веб-заземление | нет сигнала → `False` (полагаемся на reflexion) |
| `_wants_physical_browser` | agent.py | label ∈ {`physical_browser`,`play_media`,`media_control`} | физ-вкладка вместо headless | нет сигнала → `False` (headless) |
| `_is_play_intent` | agent.py | label=`play_media` | путь воспроизведения медиа | нет сигнала → `False` |
| `GROUNDING_GATE` | agent.py | mode ∈ {`reason`,`fast`} И `decision.grounding < 0.4` | эскалация к заземлению/исследованию | низкое заземление → эскалируем (безопасно) |
| intent `MIN_SIM` | intent.py | cosine-kNN уверенность < `min_sim=0.30` (per-label переопределения) | вернуть `None` (не классифицировать) | низкая уверенность → `None`, решает caller |

Деградация без эмбеддера: intent-классификатор возвращает `None` → роутинг-гейты дают `False` и
отдают решение reflexion. Это НЕ другая логика на регэкспах (feedback «no-keyword-crutches»), а мягкая
деградация к суждению reflexion. При отсутствии ключа эмбеддер печатает громкий сигнал (см.
`embedder.py`). Закреплено в `tests/test_intent_contract.py`.

## Гейты-санитайзеры ответа (что вырезать/подменить перед выдачей)

| Гейт | Где | Триггер / порог | Действие | Тип |
|---|---|---|---|---|
| `_strip_ungrounded_urls` | agent.py | домен URL не встречался в реальной выдаче (`grounded`) | `[текст](url)`→`текст`; голый выдуманный URL → вырезать | детерминированный, regex по доменам |
| `strip_ungrounded_pii` | improve/safety.py | PII (телефон/адрес/email) нет в источнике/контексте | вырезать незаземлённый PII | детерминированный |
| `is_degenerate` | semantic_signals.py | ≥60 слов И доля уникальных < `0.15` | подменить честным отказом («не удалось достоверно прочитать») | структурный, языко-независимый, без LLM |
| `_looks_like_process` | agent.py (вложенная) | текст начинается с `[шаг`/`[step`/`navigate`/`search for`/`go to`/`найти `/… | взять лучший НЕ-процессный результат шага | структурный, префиксный |
| `is_paywall` | semantic_signals.py | cosine к seed'ам стены ≥ `0.58`, маржа `0.05` над негативом | пометить контент как платный/закрытый | embedding-классификатор; нет эмбеддера → `False` |
| воспроизведение идёт (act) | browser_session `MEDIA_PLAYING` + `is_media_playing` | СТРУКТУРНЫЙ сентинел `[[MEDIA_PLAYING]]` (in-repo, ground-truth `!m.paused`) ИЛИ embedding-контраст ≥ `0.55`/`0.05` для extension-прозы | подтвердить плей детерминированно | гибрид: структурно где владеем сигналом, эмбеддинг для внешней прозы (без регэкспа по NL) |
| `is_error_page` (act) | semantic_signals.py | cosine к seed'ам «404/не найдена» ≥ `0.55`, маржа `0.05` | не заявлять плей на странице-ошибке | embedding, любой язык; нет эмбеддера → `False` |

## Гейты-судьи (финальный LLM-валидатор, любой язык, без лексикона)

| Флаг | Где | Что ловит | Действие |
|---|---|---|---|
| `false_refusal` | validation_node | ложный отказ («нет доступа», хотя данные есть/добываемы) | подменить честным статусом |
| `false_completion` | validation_node | ложь о завершении («добавил/заказал/готово») при оборванном прогоне | скорректировать на честный «не доведено» |
| `meta_stub` | validation_node | мета-заглушка вместо ответа («вот как бы я сделал…») | отклонить, требовать реальный ответ |

Судьи — семантические (LLM), специально вынесены из кода, чтобы НЕ держать лексиконные регэкспы в
агенте. Структурный сигнал «прогон оборван» (`run_status=incomplete`) подаётся судье как вход для
`false_completion`.

## Как менять
1. Порог → правишь `config.yml`, обновляешь значение в этой таблице, прогоняешь
   `tests/test_gates_characterization.py` (увидишь, что именно сдвинулось).
2. Новый гейт → добавляешь строку сюда + характеризационный тест. Иначе «башня» снова станет
   непрозрачной.
